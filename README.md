# LINE → Telegram: бот родительского чата

Сидит в родительском чате LINE, переводит всё на русский, скачивает фото и файлы,
срочное присылает в Telegram сразу, а вечером — сводку за день.

```
Родительский чат LINE
        │ webhook (каждое сообщение)
        ▼
   ваш сервер ──► Claude: перевод + «это срочно?»
        │                 └─► SQLite (история за день)
        │
        ├─► 🔴 срочное — в Telegram мгновенно, с пингом
        ├─► 🖼 фото/файлы — скачиваются и пересылаются альбомом
        └─► 🗒 20:00 — сводка за день в Telegram

   Telegram ──► /summary /todo /allevent /money /ask …
                (14 команд, см. ниже)
```

---

## Что приходит в Telegram

**Срочное — сразу:**
```
🔴 @alext СРОЧНОЕ

Ajarn Nok · ป.2/3 ผู้ปกครอง · 08:34
нужно сдать деньги завтра

Завтра принести 450 бат на экскурсию в зоопарк,
сбор у школы в 7:30.

Оригинал: พรุ่งนี้เอาเงิน 450 บาท...
```

**Фото и файлы — по мере поступления,** альбомом, с подписью «кто, когда»
и переводом текста с картинки (объявления, расписания, чеки распознаются).

**Вечером — сводка:**
```
🗒 Сводка за 2026-09-17
ป.2/3 ผู้ปกครอง · 34 сообщ. · 2 срочных · 5 вложений

📌 Главное
...
✅ Что нужно сделать
• Сдать 450 бат за экскурсию до 18 сентября
...
```

## Что понадобится

| Что | Где взять | Цена |
|---|---|---|
| LINE Official Account + Messaging API | developers.line.biz | бесплатно |
| Telegram-бот | @BotFather | бесплатно |
| Ключ Claude API | console.anthropic.com | ~$1–3/мес на обычном чате |
| Сервер с доменом | Hetzner / Timeweb / любой VPS | ~€4/мес |

**Почему VPS, а не бесплатный хостинг:** LINE шлёт вебхук ровно один раз в момент
сообщения. На free-тарифах Render/Railway контейнер засыпает и первые запросы теряются —
это молча пропущенные сообщения. Плюс вложения LINE удаляет со своих серверов через
некоторое время, поэтому качать их нужно сразу, а не «когда проснёмся».
Самый дешёвый CX22 у Hetzner (€3.79) справится с запасом.

## Установка

### 1. LINE

> Создать канал Messaging API напрямую в LINE Developers Console **больше нельзя** —
> с сентября 2024 сначала заводится Официальный аккаунт, а канал создаётся из него.
> Многие инструкции в интернете описывают старую схему.

1. [manager.line.biz](https://manager.line.biz/) → **Create LINE Official Account**.
   Заполните название, страну, категорию. Бесплатно. Может попросить подтвердить
   номер телефона по SMS.
2. В Official Account Manager → шестерёнка **Settings** → в левом меню **Messaging API**
   → **Enable Messaging API**. Попросит выбрать **provider** — создайте новый
   с любым названием.
   ⚠️ Провайдера потом нельзя ни сменить, ни отвязать.
3. На той же странице появятся **Channel ID** и **Channel secret** — secret скопируйте.
4. **Settings → Account settings** → включите
   **Allow account to join groups and multi-person chats**
   (без этого бота нельзя добавить в чат) и оставьте медиа разрешёнными.
5. **Settings → Response settings** — выключите **Chat**, **Auto-response messages**
   и **Greeting messages**, включите **Webhooks**.
   Тумблер Webhooks станет активным только после того, как будет сохранён Webhook URL
   (шаг 5 установки), так что вернитесь к нему позже.
   Greeting особенно важно выключить: иначе бот при добавлении напишет приветствие
   прямо в родительский чат, и его увидят все.
6. [developers.line.biz/console](https://developers.line.biz/console/) → войдите тем же
   аккаунтом → ваш провайдер → канал → вкладка **Messaging API** →
   **Channel access token (long-lived)** → **Issue**.
   Токен показывается целиком только один раз — скопируйте сразу.

### 2. Telegram

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. Откройте в браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` —
   найдите `"chat":{"id":123456789` — это ваш **chat_id**.

> Хотите получать сводки в отдельный чат с женой/мужем? Создайте группу,
> добавьте туда бота, и `getUpdates` покажет chat_id группы (он будет с минусом).

### 3. Claude API

[console.anthropic.com](https://console.anthropic.com) → **API Keys** → **Create key**.
Пополните баланс на $5 — этого хватит надолго.

### 4. Сервер

```bash
# на свежем Ubuntu-сервере
curl -fsSL https://get.docker.com | sh

# загрузите папку с ботом (scp / git clone) и зайдите в неё
cd line-summary-bot

cp .env.example .env
nano .env        # заполните все ключи и домен

docker compose up -d --build
docker compose logs -f bot
```

**Домен.** Направьте A-запись вашего домена (например `bot.example.com`) на IP сервера.
Caddy сам получит TLS-сертификат, как только домен начнёт резолвиться.
Порты 80 и 443 должны быть открыты.

Проверка: `curl https://bot.example.com/health` → должен вернуть `{"status":"ok",...}`.

### 5. Подключение к чату

1. В LINE Developers Console → **Messaging API** → поле **Webhook URL** →
   впишите `https://bot.example.com/webhook` → **Update** → **Verify**
   (должно быть «Success»).
2. Там же есть QR-код вашего бота. Отсканируйте его телефоном и добавьте бота в друзья.
3. Откройте родительский чат в LINE → **+** → **Invite** → выберите бота.
4. В Telegram сразу придёт `✅ Бот добавлен в чат LINE` с `groupId`.
   Впишите его в `.env` в `LINE_ALLOWED_GROUP_IDS` и сделайте `docker compose up -d --force-recreate bot` —
   тогда бот будет реагировать только на этот чат.

> **Важно:** в одном чате LINE может быть только один официальный аккаунт,
> и бот видит только те сообщения, что отправлены **после** его добавления.
> Историю чата он не подтянет.

## Команды в Telegram

Бот отвечает на команды в том же чате, куда присылает сводки. Работают у любого
участника чата; команды из других чатов игнорируются.

| Команда | Что делает |
|---|---|
| `/summary` | Сводка за сегодня на текущий момент, не дожидаясь вечера |
| `/allevent` | Все предстоящие события начиная с завтра, одним списком по датам |
| `/todo` | Что нужно сделать: сдать, принести, подписать — с дедлайнами |
| `/money` | Все денежные сборы: сумма, за что, к какому числу, кто просил |
| `/ask <вопрос>` | Свободный вопрос по переписке: `/ask когда собрание?` |
| `/search <слово>` | Поиск по сообщениям и переводам, свежие сверху |
| `/today` | Полный лог за сегодня построчно с переводом |
| `/day 2026-09-15` | Сводка за конкретную дату |
| `/media` | Переслать вложения за сегодня ещё раз |
| `/mute 8` | Приглушить срочные на N часов (по умолчанию 8, максимум 168) |
| `/unmute` | Снять паузу |
| `/status` | Жив ли бот, счётчики за день, когда следующая сводка |
| `/cleanhistory` | Удалить историю — только после подтверждения, см. ниже |
| `/help` | Список команд |

`/allevent`, `/todo`, `/money` и `/ask` работают по истории за `HISTORY_DAYS` дней
(по умолчанию 30) и пересчитывают относительные даты («в пятницу», «на следующей
неделе») в конкретные числа от сегодняшнего дня.

**Пауза (`/mute`)** не выключает бота: сообщения продолжают собираться и попадают
в сводку, а срочные приходят без звука и без упоминаний — с пометкой 🔇.

**Удаление истории (`/cleanhistory`)** сделано в два шага, чтобы нельзя было стереть
всё случайным нажатием в меню:

```
/cleanhistory              → показывает, что подпадает под удаление
/cleanhistory confirm      → удаляет всю историю
/cleanhistory 30           → показывает, что старше 30 дней
/cleanhistory 30 confirm   → удаляет только старше 30 дней
```

Удаляются сообщения, переводы, сохранённые сводки и вложения с диска. Кеш имён
участников остаётся, чтобы не запрашивать их у LINE заново. Уже отправленные
в Telegram сводки, срочные и фото никуда не денутся — чистится только база
на сервере, и восстановить её нельзя.

Команды принимаются через long polling, никакой дополнительной настройки в Telegram
не требуется — список команд бот прописывает в меню сам при старте.
Отключить приём команд целиком: `ENABLE_COMMANDS=false`.

## Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SUMMARY_TIME` | `20:00` | Во сколько приходит дневная сводка |
| `TIMEZONE` | `Asia/Bangkok` | Таймзона для сводки и группировки по дням |
| `MEDIA_DELIVERY` | `instant` | `instant` — вложения сразу; `daily` — пачкой вечером |
| `MEDIA_BATCH_SECONDS` | `45` | Сколько копить фото, чтобы отправить одним альбомом |
| `FORWARD_EVERY_MESSAGE` | `false` | `true` — присылать каждое переведённое сообщение сразу |
| `INCLUDE_FULL_LOG` | `false` | `true` — к сводке прикладывать полный лог за день |
| `MEDIA_RETENTION_DAYS` | `90` | Через сколько дней удалять скачанные файлы с сервера |
| `HISTORY_DAYS` | `30` | Глубина истории для `/allevent`, `/todo`, `/money`, `/ask` |
| `ENABLE_COMMANDS` | `true` | Принимать команды из Telegram-чата |
| `LINE_ALLOWED_GROUP_IDS` | пусто | Белый список чатов (через запятую) |
| `TELEGRAM_OWNER_USERNAME` | пусто | Кого пинговать в срочных. Несколько — через запятую: `@alex,@katya` |
| `MODEL_FAST` | `claude-haiku-4-5-20251001` | Модель для перевода каждого сообщения |
| `MODEL_SUMMARY` | `claude-sonnet-5` | Модель для дневной сводки |

Что считать срочным — правится в `app/ai.py`, в тексте `TRANSLATE_SYSTEM`.
Формат сводки — там же, в `SUMMARY_SYSTEM`; формулировки команд —
в `EVENTS_SYSTEM`, `TODO_SYSTEM`, `MONEY_SYSTEM`, `ASK_SYSTEM`.

**Справочные данные не сжимаются.** Расписания, списки тем с номерами страниц,
перечни материалов и таблицы по дням переносятся в ответ целиком: родитель
пользуется ими как памяткой и не может открыть исходный чат. Правило прописано
во всех промптах, а `/todo` при этом добавляет отдельный раздел «К контрольным
и экзаменам».

**Расписание сводится с темами.** Расписание экзаменов и список тем для повторения
почти всегда приходят разными сообщениями, иногда с разницей в дни. `/todo`
сводит их сам: день экзамена → предметы этого дня → что учить по каждому.
Названия предметов в расписании и в списке тем сопоставляются по смыслу
(«E. MATHS» и «математика» — одно и то же), а предмет, по которому тем не
присылали, помечается явно, а не пропускается.

Распознавание текста с фотографий тоже требует полной расшифровки таблиц
и списков, без «и другие темы».

## Обслуживание

```bash
docker compose logs -f bot        # логи
docker compose up -d --force-recreate bot   # применить правку .env
docker compose up -d --build      # обновление после правки кода
```

> ⚠️ `docker compose restart` **не перечитывает `.env`** — переменные окружения
> зашиваются в контейнер при создании. После правки конфига нужен
> `up -d --force-recreate`, иначе бот продолжит работать со старыми значениями.

Все данные — в папке `data/`: `bot.db` (история сообщений и переводов) и
`media/YYYY-MM-DD/` (скачанные вложения). Бэкапить достаточно её.

**Расход Claude API.** Каждое сообщение — один короткий запрос к Haiku,
каждое фото — ещё один (распознавание текста), вечером — один запрос к Sonnet.
Чат на 30–50 сообщений в день обходится примерно в $1–3 в месяц.
Чтобы урезать: поставьте `MODEL_SUMMARY=claude-haiku-4-5-20251001`.

## Безопасность

- `.env` в `.gitignore` и **не должен попадать в репозиторий** — там четыре живых
  секрета: Channel secret и access token LINE, токен Telegram-бота и ключ Claude API.
- Перед первым `git push` проверьте: `git status` не должен показывать `.env`,
  а `git log -p | grep -i "sk-ant\|bot[0-9]*:"` — ничего не находить.
- Если секрет всё же утёк: токен Telegram отзывается в @BotFather (`/revoke`),
  ключ Claude — в консоли Anthropic, access token LINE перевыпускается кнопкой Issue.
  А вот **Channel secret в LINE сменить нельзя** — только пересоздать канал.
- `ADMIN_TOKEN` защищает ручки `/admin/*`, которые умеют отправлять сообщения
  и читать статистику. Генерируйте его как `openssl rand -hex 24`, не придумывайте руками.
- Бот ничего не пишет в чат LINE и не отвечает участникам — только читает.
  Но учтите: официальный аккаунт в чате видят все участники, и в групповых чатах
  это стоит обсудить с людьми, а не ставить их перед фактом.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Verify в консоли LINE даёт ошибку | Домен не резолвится, порт 443 закрыт или контейнер не поднялся |
| Verify «Success», но сообщения не приходят | В LINE Official Account Manager не выключен режим **Chat** |
| Бота не пускают в группу | Не включён **Allow bot to join group chats**, или в чате уже есть другой официальный аккаунт |
| Вместо имён «участник 4f2a» | Родитель скрыл профиль от официальных аккаунтов — это нормально, LINE не отдаёт имя |
| Фото не приходят | Посмотрите логи: `docker compose logs bot \| grep вложени` |
| Сводка не пришла вечером | `curl .../admin/stats?token=...` — если сообщений 0, вебхук не доходит |
